# 任务功能设计

状态：已实现，按当前代码维护。

## 范围

任务由最多 50 个有序步骤组成，支持本地命令、远程命令、上传和下载。远程步骤使用任务固定主机，本地任务可以不设置主机。命令和路径按字面值处理，不提供运行时变量、条件分支、并行或跨任务依赖。

步骤默认不重试。配置重试后最多额外尝试 10 次，间隔两秒。最终失败会停止整个任务，剩余步骤标记为跳过。任意 shell 命令都可能有部分副作用，重试前需要保证幂等性。默认 sh 遇到未处理的命令错误即停止，但管道仍由最后一个进程决定退出码。选择 bash 或 zsh 会额外启用 pipefail，检查管道任意阶段的失败。条件判断、显式错误处理和 set +e 遵循所选 shell 的规则。

## 执行与审批

后端按任务 ID 限制并发，手动、定时和 AI 入口不能重入同一任务。不同任务仍可并发，操作同一服务时需要用户在脚本中协调。

每次运行提交任务版本、完整步骤和固定主机，后端读取后校验并执行这份内存快照。任务发生变化会拒绝执行。远程运行还会校验目标主机更新时间。

AI 新建、更新和运行任务始终需要人工审批，包括自主模式。运行预览包含完整步骤、主机名称、地址和端口。审批绑定任务版本、步骤和目标，执行前再次检查，发生变化后需要重新审批。命令输出作为不可信结果返回，失败或取消返回工具错误。

每个命令步骤独立启动非交互 shell，本地和远程均关闭 stdin，不提供密码输入或交互式终端。cd 和 export 不会影响后续步骤。需要提权时使用 sudo -n，模板也采用这一形式。

本地默认使用 sh（Unix）或 cmd（Windows），可选择 sh、bash、zsh、cmd 或 powershell，需要在运行设备安装对应 shell。远程默认明确使用 sh，可选择 bash 或 zsh，不再依赖账号登录 shell 的语法。Unix 命令启用 errexit，bash 和 zsh 额外启用 pipefail。Windows cmd 不加载 AutoRun，powershell 使用非交互模式。

每步默认超时五分钟，可配置为 1 至 86400 秒。正常退出后最多等待三秒读取剩余输出，防止后台进程持有管道而永久挂起。取消会清理本地进程树。远程命令超时或取消时发送 SSH KILL 信号并关闭通道；服务器是否终止脱离会话的后代进程取决于远端实现，因此不能把取消视为回滚。

本地命令默认工作目录是用户主目录，本地命令的相对 cwd 和文件传输的本地相对路径都以主目录为基准，不依赖启动应用时的目录。文件传输支持远程 ~/ 前缀。

连接按步骤延迟建立，纯远程命令只使用 SSH，不要求服务器支持 SFTP。只有实际传文件时才打开 SFTP，并复用已建立的 SSH。传输失败后的重试重新打开 SFTP，SSH 连接关闭后重新连接。

远程命令必须收到明确退出状态。信号退出或缺少退出状态均视为失败。文件传输复用 SFTP 暂存和覆盖机制，不承诺整条任务的事务性或部署回滚。

## 调度

应用打开时由前端每 30 秒检查一次调度，后端负责运行互斥和执行校验。关闭应用后不会继续触发任务，这是一项桌面辅助能力。需要持续运行的服务器任务应使用服务器调度器。

调度使用设备当前时区，时区或任务版本变化后重新建立基线。首次启用不会立即补跑。最多容忍一分钟触发延迟，超过此时间的运行直接跳过。任务仍在运行时跳过本次触发，完成后不会追赶执行。调度检查点保存在本设备。

启用状态不随 vault 同步。导出将启用状态设为 false，导入不会启用任务。同步改变步骤、主机或 cron 时暂停本机原有调度，需要重新审阅和启用。升级迁移将旧调度暂停一次，避免旧版本同步带来的自动执行。

用户可以在多台设备分别启用同一任务，这会分别执行，不提供跨设备唯一执行保证。

## 运行状态和历史

运行弹窗可以关闭，任务继续后台执行，完成时通知用户。正在运行的任务不能被前端移除，重复启动会复用现有运行。取消请求会在运行结束前重试，避免早于后端注册而丢失。

命令输出使用增量 UTF-8 解码，stdout 和 stderr 分别保留跨块字符。界面每秒最多约十次刷新，持续保留最近 200 KiB 输出，达到上限后仍能看到最后的错误。输出读取失败会导致步骤失败。

历史记录在执行前写入，写入失败则不执行命令。完成时保存步骤快照、退出码、错误原因和每步最多 8 KiB 的输出尾部，持久化失败返回错误。历史仅保存在本机，不同步；其中命令或输出可能包含敏感信息，可以清空历史。

保留最近 500 条已结束记录，运行中的记录不会被容量清理、删除或清空。启动时将未结束记录标记为中断。错误原因与日志同时展示，日志不会遮挡失败原因。

## 模板

模板是需要修改路径、主机和命令的起点。备份模板使用 PostgreSQL custom 格式，通过临时文件生成并仅在成功后替换远程备份。本地创建备份目录，已有备份先按 UTC 时间归档。下载和日志采集模板在传输前创建本地目标目录。

## 验证重点

覆盖审批后任务变化、后端并发注册与释放、取消前置竞态、本地后台输出管道、明确远程退出状态、调度错过与重入、同步设备隔离、历史运行记录保护、备份失败不覆盖旧文件和非法步骤数据。补充本地命令失败即停、bash 管道失败、自定义超时、大量输出尾部、跨块中文字符、SSH 无 SFTP 执行、远端 stdin 关闭、命令请求被拒绝，以及服务器收到取消和超时信号的回归测试。
